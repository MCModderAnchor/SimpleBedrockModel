# 1.21.1 的 2.6.0 累计更新移植

移植日期：2026-10-14。

## 来源与提交组织

- 原版本：`1.20.1-dev@c92ad1d`，累计范围 `e2919ad..c92ad1d`，共 7 个提交。
- 压缩源分支：`codex/1.20.1-2.6.0-port-source@ab49456`；父提交为 `e2919ad`，文件树与 `c92ad1d` 完全一致。
- 目标基线：`1.21.1-dev@bef0351`，此前已同步至 2.5.21。
- 将压缩源提交以 `cherry-pick -x` 导入目标，解决冲突并在同一移植提交中完成平台适配。
- 发布版本：`2.6.0-neoforge-mc1.21.1`。原源分支和源工作区保持不变。

## 同步内容与平台适配

- 网格系统从 `v2.client.world` 迁入 `v2.client.mesh`，共用捕获、GPU、绘制及缓存组件。新增即时／显式批次入口、准备与驻留预算、跨帧上传队列，以及逐实例 light／overlay 整数参数缓冲。
- 保留 NeoForge 构建、配置注册与可选兼容结构。新订阅器使用 NeoForge 的客户端 tick、渲染帧及资源重载事件；世界与开发基准使用事件的 modelView 矩阵。
- 保留目标 `addVertex`／`set*` 捕获接口、ARGB 打包和末顶点提交语义。原有普通／发光分流、QUADS／TRIANGLES、重复 buffer 顺序、法线变换和清空测试迁入新包。
- 统一通过 `MeshUpload.Payload` 同时管理 `MeshData` 与 `ByteBufferBuilder`。世界路径保留原生内存直到 SectionRenderDispatcher 的上传 future 完成；即时路径保留到预算队列上传或取消，消费、同步拒绝、异步失败和失效均释放存储。
- shader 共享参数使用 1.21.1 的 `setDefaultUniforms`。UV1／UV2 的序号和偏移读取实际顶点格式；padding 不再依赖元素列表累加。上传结束及失败时恢复调用方的 VAO 和 ARRAY_BUFFER 绑定。
- 不可渲染的主／副手实例不参与相机动画选择。Sodium polymesh 使用普通顶点写入，保留目标 Sodium／Embeddium 的方块面快速写入和独立 Embeddium 分流。
- 整理网格文档，更新 NeoForge 构建命令、资源 ID 示例、版本和下游接入边界。

## API 迁移

旧 `v2.client.world` 包的调用方需改用 `v2.client.mesh.world`、`.capture`、`.gpu` 和 `.render` 中的类型。旧 `ImmediateStaticMeshRenderer` 入口由 `StaticMeshRenderer`／`StaticMeshBufferSource` 替代，`ShardHandle` 重整为内部 GPU 组件 `WorldMeshPart`。旧包不保留转发包装。

新接口和使用契约见 [网格说明](mesh/README.md)、[即时与批量接口](mesh/static-mesh-api.md) 和 [世界渲染组](mesh/world-mesh-rendering.md)。TaCZ 等下游的 1.21.1 调用方需单独迁移，不能把 1.20.1 的接入或性能结果视为本平台验证。

## 验证

`gradlew.bat build --offline --console=plain` 通过：129 项 JUnit 测试，0 失败、0 错误、0 跳过。保留目标原有的 11 项捕获／上传回归，同步源新增的 11 项准备、驻留、整数属性及变换测试，并新增 3 项原生上传存储测试，覆盖取消 future、消费前同步失败和准入阻塞后的队列取消。

本地 `tools/run_immediate_integer_attributes_gl_check.ps1` 使用 JDK 21 和 NeoForge classpath，通过隐藏 GL 3.3 窗口进行真实像素读回。GPU 为 NVIDIA GeForce RTX 4060 Laptop，驱动 591.74。检查通过：

- 多 VAO、非 16 倍数 light／overlay、变化调用方绑定、固定发光和新 Part／VBO 复用。
- 参数表重建、同格式重新上传，以及单个属性 scope 内 32 次绘制。
- 世界 UNIFORM／FIXED／MUTABLE 光照、烘焙 overlay、UV2 重排为属性 3 且包含显式 padding 的格式。
- 真实静态缓存的 512 实例／200 键、单次编码、跨帧上传、稳定驻留、原有 VAO／ARRAY_BUFFER 绑定恢复、owner 取消和故障停用后恢复。

GL 工具沿用源项目的 Git 忽略规则，仅保存在本地开发目录；日志位于 `build/immediate-integer-attributes-gl-check/console.log`。故障停用检查会刻意写入一次 ERROR 日志，最终输出 `All immediate integer attribute GL checks passed.`。

完整游戏中的 Sodium／Iris／Embeddium／AR 组合、下游 TaCZ 接入画面和性能 A/B 尚未进行实机验证。世界透明排序、shadow 和首次准备窗口仍沿用实验性网格接口的既有边界。
